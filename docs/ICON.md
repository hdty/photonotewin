# PhotoNoteWin アイコン設計図

形状の実体は [`tools/IconBuilder.cs`](../tools/IconBuilder.cs) の `PhotoNoteMark`。
この文書はその根拠（寸法・配色・描画順）をまとめたもの。片方を直したらもう片方も直すこと。

## コンセプト（ヒエラルキー）

このアプリは**写真を撮らない**。既にある写真に「ひとことメモ」を付けて印刷する。
だから道具（カメラ・ペン）ではなく**成果物**を描く。

- **主 = 写真カード**。アイコンの中心を占める。
- **従 = メモのバッジ**。カードの右下から対角にはみ出す小さな札。
- バッジの周囲に**地色の「逃げ」**を入れてカードから浮かせる（重なりの濁り防止・小サイズでの分離）。

小サイズ（16〜24px）では「淡い写真カード＋桜色の札」の2つの塊として残り、
細部（山の稜線、メモの行）は消える。主機能は小さくても伝わり、補助機能は大きいときに現れる。

旧アイコンはカメラ＋万年筆の写実的な 3D レンダリングだった。撮影しないアプリにカメラを使うのは
カテゴリの誤りで、2つの物体が競合してシルエットが立たず、32px で灰色の塊に潰れていた。

## グリッド

- 基準グリッド **96 × 96**（Material Symbols の 24px グリッド ×4。Anchor Player と共通）
- 角丸プレート半径 **22**
- 丸終端（`LineCap.Round`）

各サイズは 96 グリッドから**直接ラスタライズ**する（大きい画像の縮小ではない）。

## 座標（96 グリッド）

| 要素 | 幾何 |
|------|------|
| プレート | `(0,0)-(96,96)` rx 22 |
| キーライン | inset 1.2 / 半径 20.8 / 幅 2.4（プレートと同心） |
| 写真カード | `x19 y18 w58 h46` rx 6 |
| 太陽 | 中心 `(63,29)` 半径 4.5 |
| 山 | `(25,58) (39,36) (49,48) (56,40) (71,58)` の多角形 |
| バッジの逃げ | `x42 y47 w42 h30` rx 7 |
| メモのバッジ | `x45 y50 w36 h24` rx 5 |
| メモの行 | `(51,58)-(75,58)` と `(51,66)-(67,66)`、幅 3.5 丸終端 |

**山の底 `y58` はカード下辺 `y64` から 6 浮かせる。** 下辺まで届かせると、山（インク）と地
（同じインク）が繋がってカードの底が抜け、写真に見えなくなる。カードは閉じたシルエットに保つ。

## 配色

ロゴの原色をそのまま使う（旧実装は 20% 白寄せしていた）。

| 役割 | 色 | HEX |
|------|-----|-----|
| プレート（地）／逃げ／山・太陽・メモの行 | インクネイビー | `#13253F` |
| 写真カード | 淡い水色 | `#A3D8E1` |
| メモのバッジ | 薄桜色 | `#E8AFCF` |
| キーライン | 淡い水色 @ 62% | `#9EA3D8E1` |

水色・桜色は HidéToys ロゴ（`assets/HideToysLogo*`）の色。

**キーラインが要る理由**: 紺プレートはほぼ黒で、Windows のダークなタスクバーは
アイコンに影も下地も付けない。縁が無いとプレートの角丸が背景に溶け、
中身だけが宙に浮いて見える。Anchor Player で実際に起きた不具合への対処。

## 描画順（`PhotoNoteMark.Draw`）

1. プレート（角丸 rx22、紺）
2. キーライン（水色 62%）
3. 写真カード（水色）
4. 太陽（紺）
5. 山（紺）
6. バッジの逃げ（紺＝地色）
7. メモのバッジ（薄桜）
8. メモの行（紺）

逃げは地色で塗るだけでよい。プレートが不透明なので合成モード（くり抜き）は要らない。

## 生成

```powershell
dotnet run --project tools\IconTool
```

- 出力: `PhotoNote/Assets/PhotoNote.ico`（16/24/32/48/64/128/256px、各フレームは PNG 埋め込み）
- 確認用（`testout/`、Git 管理外）:
  - `icon_16.png` … `icon_256.png` — 各サイズを実寸で
  - `icon_on_dark.png` — 暗いタスクバー相当 `#1b1b1b` に 48/32/24/16px を実寸で並べたもの
  - `icon_on_light.png` — 明るいタスクバー相当 `#e9e9ea` に同じもの

**512 は ICO の仕様上表現できない**（ICONDIRENTRY の幅・高さは 1 バイトで、0 が 256 を意味する）。

## 変更するとき

- `PhotoNoteMark` の定数を直し、上記コマンドで再生成する。
- `icon_16.png` / `icon_32.png` を**実寸で**見て、写真カードとメモのバッジがそれぞれ塊として
  判別できるか確認する。
- `icon_on_dark.png` で、キーラインによってプレートの輪郭が立っているか確認する。
- SVG のマスタは持たない。`CLAUDE.md` の「公開禁止: assets/ の SVG ファイル」と紛らわしくなるため、
  形状の唯一の定義はコード側（`PhotoNoteMark`）に置く。
